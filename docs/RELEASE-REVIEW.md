# 공개 전 검토 결과

검토 대상: PDF Tool Keys 0.7 공개 베타. 검토일: 2026-10-08.

[프로젝트 소개](../README.md) · [검증 기록](VALIDATION.md)

판정: **기능 확인을 마친 0.7을 고급 사용자 대상 비공식 베타로 공유할 수 있도록 문서·고지·포장을 정리한 상태**입니다. Mozilla 승인, AMO 등록 가능성, 모든 환경에서의 안정성을 인증한 문서는 아닙니다.

## 요청된 네 항목

| 항목 | 기존 패키지에서 확인한 내용 | 공개 패키지 반영 |
|---|---|---|
| 명칭·비공식 표시 | 파일명과 문서 제목이 Firefox로 시작하고 독립 프로젝트임을 충분히 설명하지 않음 | PDF Tool Keys로 명명, 비공식·비제휴 표시, 상표 귀속 고지, 로고 미사용 |
| 권한·설치·제거 안내 | AutoConfig 샌드박스 해제 설명 부족, 특정 사용자의 프로필 경로 포함, 제거·공용 설정 안내 부족 | 실행 권한과 설치 단위 영향을 설명하고 일반화된 경로 대응표·백업·프로필별 중지·완전 제거·실패 복구 절차 추가 |
| 출처·라이선스 | LICENSE 및 출처 정리 파일 없음 | 배포 코드·이전 묶음·개발 참조 소스 검토, MPL-2.0 전문·SPDX·NOTICE 추가, PDF.js의 별도 Apache-2.0 참조도 구분 |
| 검증 범위 | 모의 시험과 실제 사용 보고의 구분이 불완전하고 0.7 성공 보고 미반영 | 사용자 성공 보고 1건, 모의 시험 32개, 패키지 검사, 미검증 환경을 분리 기록 |

## 확인한 사실

- 실행 코드는 지정한 여섯 Ctrl 조합을 PDF 도구로 연결합니다. Ctrl+N 전용 명령 처리는 없습니다.
- Firefox 실행 파일·내장 PDF.js를 배포하거나 패치하지 않습니다. 코드에는 원격 다운로드·외부 데이터 전송·외부 실행 파일 실행 기능이 없습니다.
- AutoConfig에 높은 권한을 부여하는 설정은 실제로 포함되어 있습니다. 원본 파일을 수정하지 않는다는 설명만으로 이 권한 차이가 없어지는 것은 아닙니다.
- 상태 기록에는 여섯 키 코드·처리 경로·결과·오류가 포함됩니다. 일반 타이핑 이력이나 PDF 본문을 수집하는 코드와 구분하여 설명했습니다.
- 공개 패키지는 읽을 수 있는 소스와 기존 모의 테스트를 함께 제공합니다. 라이선스 고지 외에 실행 코드를 변경하지 않습니다.

## 라이선스 검토 범위

배포 대상 코드와 이전 생성 버전, 개발 중 참조한 Firefox 소스의 구성을 검토했습니다. 보관된 소스와의 줄 단위 비교에서는 긴 구현 블록의 복사를 확인하지 못했습니다. 이 결과만으로 전 세계 코드와의 일치나 모든 권리 관계를 증명하는 것은 아니므로 독창성 인증이라고 표현하지 않습니다.

독립 작성한 연결 코드의 배포 조건을 명확히 하고 Mozilla 소스를 참고한 맥락을 투명하게 남기기 위해 MPL-2.0 배포안으로 정리했습니다. 외부 라이브러리 전체나 원본 파일을 포함하지 않으며, 참조한 원자료별 라이선스는 NOTICE에 구분했습니다. 향후 제3자 코드를 추가하면 그 부분의 라이선스를 새로 검토해야 합니다.

## 남아 있는 제한

사용자 한 환경의 정상 작동 확인을 광범위한 호환성 검증으로 확대하지 않았습니다. 새 환경의 설치·제거, 다른 브라우저 버전, 추가 사용자 사용성은 별도 검증이 필요합니다. 일반 확장 기능이 아니므로 AMO 서명·심사·부가 기능 관리자 제거를 제공하지 않습니다. 공개 저장소나 다운로드 페이지에 게시하는 작업은 이 패키지 작성에 포함하지 않았습니다.
